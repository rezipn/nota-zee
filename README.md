# NotaZee 🧾

Bikin nota & invoice tinggal isi, langsung jadi.

## Fitur
- Profil toko + upload logo
- Nomor nota otomatis, tanggal, pelanggan, catatan
- Item dengan harga format rupiah + terbilang otomatis
- Diskon & pajak toko (PPN / Service / Pajak Restoran, % bisa diubah)
- 8 template: Minimal, Struk Thermal, Elegan, Klasik Biru, Modern Merah, Ombak, Vintage, Hijau Ombak
- Download / Print PDF (1 halaman A4)
- Animasi: maskot nota, background gradien + blob, toggle pajak

## Stack
Angular (standalone, SCSS, signals) + Poppins
